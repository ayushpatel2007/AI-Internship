# AI Internship Projects - Codec Technologies

This repository contains the projects completed during my AI Internship. As per the requirements, I have developed two distinct AI systems using Python and Google Colab.

---

## Project 1: Movie Recommendation System
**Objective:** To suggest movies to users based on their rating history and similarities with other users.

- **Technique:** Collaborative Filtering.
- **Algorithm:** Correlation-based similarity.
- **Dataset:** MovieLens 100k (943 users, 1682 movies).
- **Key Libraries:** Pandas, NumPy, Scikit-learn.

## Project 2: Spam Email Classifier
**Objective:** To detect and filter spam emails/messages based on their textual content.

- **Technique:** Natural Language Processing (NLP) & Classification.
- **Algorithm:** Multinomial Naive Bayes.
- **Dataset:** SMS Spam Collection.
- **Key Libraries:** Scikit-learn (CountVectorizer), Pandas.

---

## How to Run These Projects
These projects are optimized for **Google Colab**. 

1. Open the desired `.ipynb` file in this repository.
2. Click the **'Open in Colab'** badge.
3. In Colab, go to **Runtime > Run all** to see the results and accuracy scores.
