# Movie Recommendation System

## Project Overview
This project is part of my AI Internship. It is a recommendation engine that suggests movies to users based on their interests and past behaviors.

## Implementation Details
- **Type:** Collaborative Filtering.
- **Algorithm:** Used Correlation-based similarity to find movies that have similar rating patterns.
- **Dataset:** MovieLens 100k dataset (contains 100,000 ratings from 943 users on 1,682 movies).

## Tools & Libraries Used
- **Google Colab:** Cloud environment for development.
- **Python:** Primary programming language.
- **Pandas:** For data manipulation and creating user-item matrices.
- **NumPy:** For numerical operations.
- **Scikit-learn:** For calculating similarity metrics.

## How to Run
1. Open the `.ipynb` file in this repository.
2. Click the **"Open in Colab"** badge at the top.
3. Run all cells to see the recommendations in action.
